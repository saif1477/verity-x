# LIMITATIONS

1. **Synthetic only** — not official government records; watermark on every UI surface.
2. **Does not accuse** — investigation risk ≠ guilt; hypotheses are possible explanations.
3. **No LLM required** — core path is deterministic; any future LLM must not invent evidence.
4. **Simplified expected trajectories** — S-curve heuristics, not full engineering schedules.
5. **Entity resolution** is lightweight; contractor concentration is scenario-labeled, not graph-proven guilt.
6. **PDF export** via browser print; structured source of truth is JSON case file.
7. **Full Python/FastAPI/Alembic/Playwright monorepo** is specified in the product vision; this deployment implements the vertical slice on Vite + serverless + Supabase with equivalent algorithms and APIs.
8. **Evaluation metrics** are illustrative on synthetic ground truth — not certified forensic performance.
9. Counterfactuals are **sensitivity analyses**, not causal identification.
10. Human review required before any real-world operational action (this demo is not for enforcement).
